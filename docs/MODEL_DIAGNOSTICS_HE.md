# דיאגנוסטיקת מודלים

ערכים שלושת מודלי הזיהוי הלא-מפוקחים מפיקים לכל סבב ניתוח. אלה
המספרים שמופיעים בלשוניות ה-Analysis Insights ונשמרים במילון
הסבב (‏`ip_agg.attrs`) לבחינה מאוחרת.

## מה קבוע ומה מסתגל

| מודל | שדה | ערך או דרך הבחירה |
|---|---|---|
| IsolationForest | `contamination` | **קבוע על 0.10** (עם `n_estimators=200` ו-`random_state=42`). סריקת יציבות קודמת על `[0.05, 0.10, 0.15]` × 5 ‏seeds מול אמת-מידה מתויגת הביאה לאותו F1 כמו 0.10 הקבוע (0.250 מול 0.247), במחיר של פי-15 אימוני יער - ולכן הסריקה בוטלה. ראו `docs/TRADEOFFS_EN.md`. |
| IsolationForest | `#anomalies / #IPs` | ספירת השורות שבהן `predict() == -1` על מטריצת המאפיינים לכל כתובת IP |
| DBSCAN | `eps` | מרפק של k-distance (עם ‏k=2) בנקודת המינימום של הנגזרת השנייה. ‏Fallbacks: ‏`1.3` כשיש פחות מ-4 כתובות IP, ו-`max(mean(k_dist), 0.05)` כשהמרפק קורס לאפס (הצפות עם מקורות מזויפים). |
| DBSCAN | `min_samples` | קבוע על 2 |
| DBSCAN | `clusters / noise` | ספירת תוויות שאינן רעש / ספירת תוויות `-1` |
| DBSCAN | `silhouette` | מחושב על הנקודות שאינן רעש כשיש לפחות שני אשכולות, אחרת `n/a` |
| DBSCAN | `>5000 IPs` | **מדלג לגמרי** (כל שורה מקבלת `cluster = -1`) כדי להימנע מהתפוצצות O(n²) של חישוב השכנים שנצפתה בהצפות מזויפות |
| LSTM | `threshold` | הנוסחה `val_mean + 2·val_std` של שגיאת החיזוי לכל רצף, מחושבת על מקטע הוולידציה המופרש |
| LSTM | `#flagged / #sequences` | רצפים ששגיאתם חרגה מהסף |
| LSTM | סף אימון | דורש לפחות 20 מקטעי-שנייה שמישים (‏`SEQ_LEN=10` מותיר 10 חלונות גולשים). הקלטות קצרות יותר מדלגות על LSTM בשקט, והחוקים הדטרמיניסטיים מכסים אותן. |

## מטריצת המאפיינים

IsolationForest ו-DBSCAN חולקים מטריצת מאפיינים של 10 עמודות לכל
כתובת IP (מנורמלת עם `StandardScaler`):

```
mean_len, std_len, count, burst_score, unique_dsts,
syn_count, rst_count, fin_count, null_count, xmas_count
```

ה-LSTM רץ על אות זמני נפרד: גודל חבילה ממוצע לכל מקטע של שנייה
(ממולא באפסים בשניות שקטות), מחולק לרצפים ומקבל ציון לפי שגיאת
החיזוי. השניות נמדדות לפי שעון הקיר - לא "שניות עם תעבורה" - וזה
מה שגורם לפערי שקט ארוכים להופיע כפרצים חריגים בשני הקצוות.

## ה-attrs שנשמרים ב-`ip_agg`

נכתבים על ידי `run_ml_on_session`, זמינים ב-`S['ip_agg'].attrs`
לתצוגת ה-Model Diagnostics בדשבורד:

```
_chosen_contamination   0.10 היום (קבוע)
_eps_auto               ה-eps שנבחר (מרפק / fallback / רצפה)
_min_samples            2
_silhouette             float או None
_n_clusters             int
_n_noise                int
```

## תרשים הרגישות ל-contamination

התרשים `sensitivity_sweep` בדשבורד עדיין מאמן 20 מודלי
IsolationForest לאורך הטווח `contamination = 0.02 .. 0.30` ומצייר
קו אנכי על הערך שבו משתמשים בפועל (`0.10`). זה כלי להמחשת האיזון -
לא בורר ערך. הפרודקשן משתמש תמיד ב-0.10.
